# Contributor Covenant Code of Conduct

## Our Pledge

We as contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Using welcoming and inclusive language.
- Being respectful of differing viewpoints and experiences.
- Gracefully accepting constructive criticism.
- Focusing on what is best for the community.

Examples of unacceptable behavior include:

- Harassment, intimidation, or discrimination.
- Degrading comments or personal attacks.
- Public or private harassment.
- Excessive profanity or derogatory language.

## Scope

This code of conduct applies to all project spaces, including issue trackers, pull requests, discussion forums, and public or private communications related to the project.

## Enforcement

Project maintainers may remove or edit comments, disable user accounts, or take other actions if behavior violates this code of conduct.

If you experience or witness unacceptable behavior, please report it to the project maintainers.
